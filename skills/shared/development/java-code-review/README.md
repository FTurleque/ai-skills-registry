# Java Code Review

> Analyse structurée du code Java pour identifier les défauts, risques et améliorations possibles.

---

## Présentation

Ce skill guide un assistant IA dans la réalisation d'une revue de code Java complète et structurée. Il couvre la lisibilité, la robustesse, la sécurité, les performances et la compatibilité avec la version Java cible.

## Prérequis

- Fournir le code Java complet ou les extraits significatifs à analyser
- Indiquer si possible la version Java cible du projet
- Décrire optionnellement le rôle de la classe dans l'application

## Utilisation

1. Fournir le code Java à l'assistant IA
2. Indiquer la version Java cible (ex. Java 17)
3. Demander une revue en utilisant ce skill
4. L'assistant produira un rapport structuré

## Exemple de prompt

```
Effectue une revue de code Java sur la classe suivante. Le projet cible Java 17.

[code Java]
```
