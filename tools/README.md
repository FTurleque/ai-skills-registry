# Outils et utilitaires

Ce dossier est prévu pour accueillir des scripts ou utilitaires liés à la gestion du dépôt **AI Skills Registry**.

---

## Contenu actuel

Ce dossier est actuellement vide. Des outils pourront être ajoutés à mesure que le dépôt évolue.

---

## Exemples d'outils envisageables

- **Validation de métadonnées** : script pour valider tous les `metadata.yaml` contre le schéma JSON
- **Génération d'index** : script pour générer une liste de tous les skills disponibles
- **Vérification de cohérence** : script pour vérifier que les champs `name` correspondent aux noms de dossiers

---

## Conventions

- Les scripts doivent être documentés
- Ne pas ajouter de dépendances inutiles
- Préférer des scripts simples et portables (shell, Python standard)
- Les scripts ne font pas partie des skills eux-mêmes
