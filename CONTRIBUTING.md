# Guide de contribution

Merci de votre intérêt pour ce projet. Ce document décrit les étapes recommandées pour contribuer au dépôt **AI Skills Registry**.

Voir aussi [docs/contributing.md](docs/contributing.md) pour le processus détaillé.

---

## Prérequis

- Connaître le format standard d'un skill (voir [README.md](README.md))
- Respecter les conventions du dépôt (voir [docs/conventions.md](docs/conventions.md))
- Vérifier la compatibilité avec les outils ciblés (voir [docs/compatibility.md](docs/compatibility.md))

---

## Processus rapide

1. Copier `templates/skill-template/` dans la catégorie adaptée
2. Renseigner les métadonnées et rédiger les instructions
3. Ajouter des exemples
4. Mettre à jour `CHANGELOG.md`
5. Créer une pull request avec la checklist complétée

---

## Code de conduite

- Respecter les autres contributeurs
- Proposer des améliorations constructives
- Ne pas inclure de secrets, tokens ou informations personnelles sensibles

---
