# Nom du Jeu d'Instructions

À quel type de projet ce contexte s'applique : langage, outillage, forme du dépôt.

## Ce que ça change

Ce qu'un agent fait mieux, ou cesse de faire de travers, avec ce fichier en place.

## Installation

```bash
cp instructions/<nom>/CLAUDE.md /chemin/du/projet/CLAUDE.md
```

Puis remplir les sections : un gabarit non rempli est pire que pas de gabarit, parce qu'il consomme
du contexte à chaque session sans rien apporter.

## Ce qu'il faut adapter

La liste des sections à remplir obligatoirement, et celles qu'on peut supprimer.

## Limites

Ce que ce jeu d'instructions ne couvre pas. Section obligatoire.
